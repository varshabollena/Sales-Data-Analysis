# Sales Data Analysis Report

## Project Overview

The Sales Data Analysis project uses Python and the pandas library to analyze a sales dataset. The goal is to extract useful insights such as total revenue, average sales value, and the best-selling product.

## Objectives

* Learn basic data analysis using Python
* Use the pandas library for data manipulation
* Handle missing values in datasets
* Calculate key sales metrics
* Generate a simple analysis report

## Setup Instructions

1. Install Python
2. Install pandas library

pip install pandas

3. Download the project files
4. Run the program

python sales_analysis.py

## Code Structure

sales_analysis.py – Main analysis program
sales_data.csv – Dataset used for analysis
analysis_report.md – Project documentation
requirements.txt – Python dependencies

## Analysis Steps

1. Load dataset using pandas
2. Display first few rows using head()
3. Check dataset structure using info()
4. Detect missing values
5. Clean data by filling missing values
6. Calculate sales metrics
7. Display results in a formatted report

## Metrics Calculated

* Total Sales Revenue
* Average Sales Value
* Maximum Sale Value
* Best Selling Product

## Example Output

Total Revenue: ₹1,635,000
Average Sale Value: ₹163,500
Highest Sale: ₹300,000
Best Selling Product: Phone

## Conclusion

This project demonstrates how Python and pandas can be used to analyze real-world datasets. It shows how to clean data, calculate statistics, and generate insights from sales information.
